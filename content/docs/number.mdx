Number dibuat dengan `z.number()`. type yang di kembalikan berupa `number`.

## Penggunaan

<Tabs items={["form.tsx", "schema.ts"]}>
<Tab>

```tsx

"use client";

import { useForm } from "@tanstack/react-form";
import { ErlForm } from "erlangform";
import { schema } from "./schema";

export default function AgeForm() {
  const form = useForm({
    defaultValues: { age: 0 },
    validators: { onChange: schema },
    onSubmit: ({ value }) => console.log(value),
  });

  return (
    <form onSubmit={(event) => { event.preventDefault(); form.handleSubmit(); }}>
      <ErlForm
        form={form}
        schema={schema}
        fieldConfig={{
          age: {
            label: "Umur",
            placeholder: "Masukkan umur",
          },
        }}
      />
      <button type="submit">Simpan</button>
    </form>
  );
}
```

</Tab>
<Tab>

```tsx
import { z } from "zod";

export const schema = z.object({
  age: z.number("Umur harus berupa angka").min(1, "Umur harus lebih dari 0"),
});
```

</Tab>
</Tabs>

`fieldConfig.age` diterapkan ke field `age` karena nama key-nya sama dengan property di schema.
